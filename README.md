# 🎯 Number Guessing Game

A simple and fun **Number Guessing Game** built using **HTML, CSS, and JavaScript**.  
The player has to guess a randomly generated number between **0 and 100**.  
With every wrong guess, the score decreases until the correct number is found.

---

## 🚀 Live Preview
You can run this project locally or deploy it using **GitHub Pages**.

---

## 🕹️ How to Play
1. Enter a number between **0 and 100**.
2. Click the **Guess** button.
3. The game will tell you whether your guess is:
   - Too high  
   - Too low  
   - Correct 🎉
4. Your score starts from **100** and decreases with every guess.
5. Once the correct number is guessed, the game ends.

- User-friendly messages

---

## 🧠 Game Logic Overview
- A random number is generated using `Math.random()`
- User input is compared with the generated number
- Feedback is shown after every guess
- Score decreases by 1 on every attempt
- Input is disabled after winning
